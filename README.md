# GPT Rules

这个仓库用于保存和同步我在不同设备上使用的 Codex 全局 `AGENTS.md`。

换设备后，需求确认、修改范围、开发习惯和交付要求应保持一致。规则统一维护在这里，各设备同步同一份内容。

## 当前规则

| 文件 | 用途 |
| --- | --- |
| [中文主文件](./Sudark（Mac）/agents.md) | 当前使用的完整规则，各设备以这份文件为准。 |
| [英文参考](./Sudark（Mac）/agents-en.md) | 尚未与当前中文版同步，保留作参考。 |

当前中文主文件仍放在 `Sudark（Mac）` 目录下，各设备都从这份文件同步。

## 跨设备同步

1. 在另一台设备开始工作前，从仓库获取最新的中文主文件。
2. 用完整内容更新该设备实际使用的全局 `AGENTS.md`。
3. 在某台设备调整规则后，将完整文件更新回仓库，再同步到其他设备。

可以直接在 GitHub 上查看和更新文件。同步以完整文件为单位，避免各设备因只复制部分条目而逐渐产生差异。

## 规则范围

- 协作方式：通过 QA Tool 提问，明确任务直接执行，修正前核对修改范围。
- 授权边界：对齐业务范围、设计方向、架构变更和新增 production dependency。
- 开发与验证：日常交付节奏、Web 基础视觉检查、Java / Minecraft 编译约定和部署前验证。
- Git 与存档：提交信息格式、原生 Git 操作和本地 checkpoint 流程。
- 项目约定：Minecraft 颜色格式、文件与目录别名、关联更新和过程说明。

完整要求以中文主文件为准。文件中涉及的本地路径、目录别名和项目专属约定，在各设备上使用时需要结合实际环境核对。
